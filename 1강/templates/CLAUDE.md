# CLAUDE.md — 프로젝트 규칙

## 처음 실행할 때

`BOOTSTRAP.md`가 있으면 그것부터 따라간다. 텔레그램 연결부터 정체성 설정까지 안내하는 첫 대화 스크립트다 — 다 끝나면 스스로 삭제된다.

## 파일 소유권 (중복 기록 금지)

정보는 한 곳에만 기록합니다. 같은 내용을 여러 파일에 적지 마세요.

- `SOUL.md` — 에이전트가 **어떻게 행동하는가** (성격, 말투, 원칙)
- `IDENTITY.md` — 에이전트가 **누구인가** (이름, 이모지, 아바타)
- `USER.md` — 유저가 **누구인가** (역할, 선호, 배경)
- `CONTEXT.md` — 에이전트가 **작업하려면 알아야 하는 것** (환경, 자주 쓰는 도구, 세팅)
- `MEMORY.md` — **무슨 일이 있었는가** (기억할 만한 사건, 결정, 마일스톤)

하나의 정보가 여러 곳에 해당될 것 같으면, 가장 핵심적인 한 곳에만 적으세요.

## 언제 업데이트하나

대화 중 아래 같은 순간을 만나면, 유저에게 알리지 않고 그 자리에서 조용히 해당 파일을 고칩니다.

- 유저가 자기 얘기(역할/선호/배경)를 하면 → `USER.md`
- 유저가 말투나 태도를 교정하면 → `SOUL.md`
- 이름이나 이모지를 새로 정하거나 바꾸면 → `IDENTITY.md`
- 새로운 프로젝트·도구·작업환경을 알게 되면 → `CONTEXT.md`
- 나중에도 참고할 가치가 있는 사건·결정이 있으면 → `MEMORY.md`

## 텔레그램 응답 포맷

- reply 호출 시 format: "markdownv2" 필수
- 굵게는 *별표 한 개* (두 개 아님), 기울임은 _밑줄_
- 본문 특수문자 `_*[]()~>#+-=|{}.!` 와 백틱은 `\`로 이스케이프
- 코드/코드블록 안은 이스케이프 안 함(단 그 안의 백틱과 역슬래시는 이스케이프)
- URL은 `[텍스트](주소)` 형태로

## 세션 시작 시 항상 읽는 파일

`SessionStart` 훅(`hook_session_start.py`)이 매 세션마다 아래 순서로 자동으로 읽어 컨텍스트에 주입합니다.

1. `SOUL.md`
2. `IDENTITY.md`
3. `USER.md`
4. `CONTEXT.md`
5. `MEMORY.md`

파일에 직접 손으로 적어도 되고, 대화 중에 에이전트가 알아서 채워나가도 됩니다.
